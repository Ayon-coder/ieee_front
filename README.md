# IEEE SB AOT Website

A modern, fast, and responsive web application for the IEEE Student Branch of Academy of Technology (IEEE SB AOT). Built using React, Vite, and Tailwind CSS.

## Features
- **Modern UI**: Powered by Tailwind CSS and custom design tokens (Material Design 3 inspired).
- **Fast Navigation**: Client-side routing with React Router.
- **Lightning Fast Tooling**: Built with Vite and Bun.

## Prerequisites
- [Bun](https://bun.sh/) installed on your machine.

## Getting Started

1. **Install dependencies:**
   ```bash
   bun install
   ```

2. **Start the development server:**
   ```bash
   bun dev
   ```

3. **Build for production:**
   ```bash
   bun run build
   ```

## Project Structure
- `src/components/`: Reusable React components (Navbar, Footer, etc.).
- `src/pages/`: Main application pages (Home, Events, Teams, Contact).
- `src/index.css`: Global styles and Tailwind configuration.
